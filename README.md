# 河科大洛尘志愿填报

> 用数据读懂录取，让每一分都有去处。

一个面向河南科技大学高考志愿填报的**单页开源工具**。输入分数或位次，基于学校官方公布的录取数据，智能测算录取概率、生成「冲 / 稳 / 保」志愿方案，并附带每个专业的实力介绍与就业前景分析。

**完全静态、零依赖**：整个网站就是一个 HTML 文件加一张图片，双击即可运行，无需服务器、无需构建、无需联网。

---

## 功能特性

| 功能 | 说明 |
|------|------|
| 🎯 智能志愿推荐 | 输入分数或位次，自动换算，按位次比值划分冲刺 / 稳妥 / 保底三档，给出每个专业的录取概率 |
| 📊 专业录取数据库 | 收录 2025 年在豫本科批全部 111 个招生专业的最低分、最低位次、专业组与录取人数，支持搜索与按学科门类筛选 |
| 🏛 专业深度分析 | 36 个重点专业 + 9 大学科门类的档案，涵盖河科大专业实力、学什么、就业方向、就业前景、报考提示 |
| ⚙️ 灵活筛选 | 物理类 / 历史类切换、选考科目筛选、是否包含中外合作、冲刺强度调节 |
| 📥 品牌画幅 | 科技风格站点横幅，站名清晰呈现，支持一键下载 |
| 📱 响应式 | 桌面端与移动端自适应 |

## 数据来源

本项目的录取数据来自**河南科技大学招生就业办公室**公开信息：

- 录取数据：[2023 年-2025 年河南省录取情况](https://zjc.haust.edu.cn/info/1143/25635.htm)，采用其中 **2025 年（河南新高考首年）** 本科批各专业数据
- 省控线（2025 年河南本科批）：物理类 427 分 / 历史类 471 分
- 学校概况与国家级一流本科专业名单：河南科技大学官网及招生网
- 就业数据：河科大就业质量报告及公开招聘薪酬统计（为全国 / 行业参考值）

### 算法说明

- **分数 → 位次换算**：依据本校 2025 各专业「分数—位次」对应点做线性插值；直接输入位次更准确
- **分档逻辑**：以「你的位次 ÷ 专业录取位次」的比值 `k` 分档
  - `k ≤ 0.85` → 保底
  - `0.85 < k ≤ 1.02` → 稳妥
  - `k > 1.02` → 冲刺（上限可调）
- **概率模型**：基于 `k` 的分段线性映射（`k=0.7` 约 96%，`k=1.0` 约 55%，`k=1.3` 约 12%）

## 技术栈

- **HTML5**：语义化结构
- **CSS3**：CSS 变量、Grid / Flexbox 布局、渐变、动画、玻璃拟态

## 二次开发

克隆后可直接修改 HTML 文件中的数据数组：

```js
const PHYS = [...];         // 物理类专业数据
const HIST = [...];         // 历史类专业数据
const RANK_REF = {...};     // 分数-位次换算参照点
const PROFILE = {...};      // 重点专业档案（官方 + 就业分析）
const CAT_PROFILE = {...};  // 学科门类通用档案
```

每条专业数据格式为：

```js
["专业名称", "学科门类", 最低分, 最低位次, "专业组", 录取人数, "标签", "类型"]
// 类型：n=普通 / c=中外合作 / a=应用工程学院 / chembio=需化学+生物
```

修改后刷新页面即可生效。
